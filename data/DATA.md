## Naturalness Evaluation

The file [naturalness-instructions.csv](naturalness-instructions.csv) presents the list of the 80 instructions that were randomly selected for the evaluation of naturalness rated by the LLM judge (GPT-5-mini) and 11 human evaluators.
Half of the instructions were generated by Claude-Opus-4.6 Incremental (digit) and half was selected from LaM-Pilot's dataset (baseline).

The following data files present the naturalness ratings from the LLM judge and the human evaluators on the selected subset of instructions.

| File                                                     | Evaluators |
| -------------------------------------------------------- | ---------- |
| [eval-human-naturalness.csv](eval-human-naturalness.csv) | Humans     |
| [eval-llm-naturalness.csv](eval-llm-naturalness.csv)     | LLM        |
